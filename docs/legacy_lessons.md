- **S2：检查 GitHub 代码.txt**，SHA256 `50ad2c0d88c40ff6cccfc726b73613a36cba3e66e34ea2dc341819285401472a`。来源结构：地图生产混杂、修改方式、已报告修复、编辑入口、文档字段、实际验证与未验边界。

## 不应歪曲的历史验证结果

S1末尾明确：文档基本接顺，但第一章地图、相机、人物比例、门宽、移动手感、节奏和3–5天可玩性仍需QA；不能把“文档没断链”说成游戏流畅。
S2“实际验证”报告过核心11/11，首屏23检查0失败；同时说明另外21项地图测试登记但当轮未执行、视觉与全路径未验。其测试结果只属于当时范围，不能转移到新项目。
S2记录的冷导入约92秒/76.5秒是**引擎导入**，没有完整生图服务计时；不能引用这些数字证明模型生成慢或宣称新流程快几倍。
