# 验收与发布

## 分清四类结论
文档/工具检查、领域/场景自动回归、原生视觉与交互、导出包实际游玩分别记录。PixelLab连接、真实生成、真实LLM调用另列。没有执行的项写未验，不用“CI绿”概括全部。
证据用[记录模板](../templates/validation_report.md)，绑定commit、平台、引擎、入口、命令、预期/实际及原始日志。测试自己的超时/错误分类须保留失败反例。

## 制作与引擎门
素材来源和许可完整，PNG/帧数/时长/锚点通过；Wang转换角点/边模式正确，tile全组合与门桥实际通行；四向人犬和contact动作同标尺。
导入与运行共同拒绝未声明的ERROR/SCRIPT ERROR/SHADER ERROR/Parse Error；不能只查终结PASS。负向测试允许的诊断按精确用例/类型/次数登记，多一条仍失败。退出码、超时、终结标记都校验。
新工程检查从冷checkout与无缓存导入开始；更新资源只增量开发，发布前仍做冷导入。新字体必须打包，不能由系统字体掩盖缺字。

## 正常三天路线
第一天：从标题新档输入名字，带狗出生，实际进家开箱子；到店购买、工坊拜访、两居民交流；自己整地播种浇水，回家休息。
第二天：经过正常日结，再浇水、交流或完成委托；观察居民工作/休闲/夜间变体及真实知识边界；休息。
第三天：收玩家自己种的作物，出售/交付并补种；完成指引、委托、故事行动与回访、狗在场经历。保存退出、关闭进程再继续，状态一致。
教程成熟田、debug加物、强制传送、测试快进不能代替这条玩家路径。

## 阻塞矩阵
移动：门、桥、树前后、墙角、田边；四向/斜向、急转/停走、玩家狗/NPC拥堵；100次双向人犬门切换无丢失/卡墙。
钱物：满包采收/领奖、余额或材料不足、同ID重放/异payload、错目标、赠礼和交付区分；失败不扣、恢复不重奖。
生命周期：失焦、菜单打开关闭、加载/操作取消、目标消失、日边界、连续休息、保存失败、坏档、未知版本；不半恢复、不覆盖好档、不访问旧项目用户目录。
UI：1280×720与1920×1080标题、背包、箱子、交易、任务、对话、设置、暂停/读档；焦点、说明、图标、长中文、非书法字体、数量与禁用原因无裁切。
AI：默认关闭、无Key/断网/429/超时/旧会话/畸形回复；钱物和进度完全不变。PixelLab断开不影响离线运行与打包资源。

## 发布
至少一个明确桌面平台的导出包，在无编辑器/无项目缓存环境从真实标题完成三天路线；核对字体、许可、资源及无密钥/生产缓存。只报告实际验证的平台。
记录冷启动、导入及帧时间实测，录屏60FPS不是运行性能证据。阻塞性穿模/数据丢失/软锁清零后才标playable。其他不足单列；生成图片成功或新仓库架子完成不能关闭总任务。
