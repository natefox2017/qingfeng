# 产品与首版可玩范围

## 决定
用户决定：全新项目；星露谷式相机和像素设计；融入 a16z AI Town 与 my_ai_town 的居民体验/技术；第一版能正常游玩；图标按钮优先、替换书法字体；PixelLab 加入制作工具链。
本项目选择：单机、核心离线可玩、固定地图、有限居民活动，AI 只增强表达。下面是新执行范围，不是旧项目审批或参考游戏的原样规则。

## 核心循环
标题 → 新档命名 → 带狗到农庄 → 箱子/工具 → 整地播种浇水 → 村庄购买/出售/交流 → 回家休息 → 正常生长成熟 → 采收交付或出售 → 补种 → 保存退出 → 重启继续。
教程成熟田提供即时反馈，但验收必须种出玩家自己播下的作物。

## 首版预算
两个可走区域：农庄、村庄；三个可进室内：家、商店、工坊；玩家、狗、三居民；先一种作物完整循环。居民私宅可复用房间，不计额外可玩室内，但每个回家目标须是真实合法锚点。
三条可任意顺序推进的开局指引：安顿家中、认识邻里、第一份收成。再有一条真实物品委托、一段有行动与回访的居民故事、一次狗实际在场的共同经历。
页面包括标题、新档、读档、HUD/快捷栏、背包、箱子、交易、对话、任务、设置、暂停保存。首版至少一个目标桌面包连续可玩三天。

不做：整图 AI 生成、联网多人、30 人完全自治社会、复杂工业链、婚育、强制战斗、生存/体力惩罚、工具损坏、强制向量数据库和游戏运行时出图。旧四章、旧区域/人物审批不作为隐含欠账；新的具体文化题材、主角样貌在首屏样板确定，不恢复旧图。

## 操作与规则
输入表由 WORLD 单一维护：WASD/方向键移动，E 交互，B 背包，Esc 取消最上层/暂停，数字键选槽；鼠标使用物品和指向目标须明确，不让门、NPC、农具同时吃一个操作。
种植按日结：没浇水只停止生长，不销毁；成熟满包不删作物；翻地/播种/浇水/收获在动作 contact 事件验证一次并提交，执行前取消零成本，恢复动作不得重复提交。
所有钱物、买卖、箱子转移、任务交付和赠礼由确定性命令结算。柜台服务不依赖居民正在闲聊，也不依赖模型回复。
游戏分钟只有一份；背包/交易/设置/玩家对话/失焦暂停，NPC 自主交流不冻结世界。床推进到下一日初；跨过的日结按顺序结算且去重，退出期间不惩罚。
容量、初始种子与钱、价格、营业窗口、日长、成长天数由 CORE 的 content_version 数据表统一定义；不能在 UI 和领域各写一套常量。首作物须在正确操作时第三天成熟。耗光钱和种子仍有可再生采集出售等正常恢复途径，不靠 debug 解锁。

## 居民体验
三人分别承担杂货、工坊、邻里职责；有工作、公共活动、交流、回家及雨天/夜间变体。先确保服务时段可玩，再允许有限空闲选择，不承诺完整社会模拟。
客观事件与私人理解分离。居民仅从亲历、观察、被告知获得记忆，不能把全局日志当全员全知。失败交易不是成功经历；每日重复寒暄/赠礼不能无限刷关系。
无网络也有条件对白与故事。AI 回包只显示文本和合法事实引用，不发物品、不改价、不完结任务、不改坐标。内容数量扩展须在首版实际游玩后另定。
